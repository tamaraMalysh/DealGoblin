# Agent Docs Index

Use this folder as the detailed system of record referenced by `/AGENTS.md`.

## Loading Order
1. Start at `/AGENTS.md`.
2. Open `project.md` for scope, goals, and current-state assumptions.
3. Open `commands.md` for setup/check command canon.
4. Open `standards.md` for coding, testing, and security expectations.

Load only the files needed for the current task to keep context focused.

## Which File To Use
- Scope clarification, goals, non-goals: `project.md`
- Setup/test/lint/format/typecheck commands: `commands.md`
- Code quality and documentation expectations: `standards.md`

## Maintenance Rule
- When any command or policy changes, update both the detailed file here and the short summary in `/AGENTS.md`.
